# PortfolioHUB

Repositório criado para armazenar e apresentar projetos acadêmicos e pessoais, integrado com o GitHub Pages.

**Acesse o portfólio online:** https://github.com/brunozieglervargas-hash/portfolio-hub/edit/main/README.md

## Projetos
* **Calculadora:** Projeto simples desenvolvido em HTML.

## Tecnologias Utilizadas
* HTML
* Git e GitHub
* Google Workspace (Integração)

## Documentação de Configuração e Colaboração
Este ambiente foi configurado para permitir o controle de versão e o compartilhamento de código seguro. 
* **Colaboração:** Qualquer novo projeto ou alteração deve ser feito através de *Branches* separadas e enviado para a branch `main` apenas via *Pull Requests*.
* **Integração:** O deploy contínuo é realizado através do GitHub Pages, atualizando o site automaticamente a cada novo *commit* na branch principal.

## Gestão de Usuários e Segurança
Para garantir a conformidade com as melhores práticas de segurança:
1. A branch `main` está protegida contra *commits* diretos acidentais.
2. Apenas usuários autorizados (proprietário) têm permissão de aprovar alterações.
