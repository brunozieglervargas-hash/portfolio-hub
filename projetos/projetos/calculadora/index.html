Sobre o Projeto

Este sistema foi desenvolvido como critério avaliativo para a faculdade, aplicando conceitos práticos de HTML5 semântico, estilização avançada com CSS3 e manipulação de eventos em JavaScript puro (Vanilla JS).

O foco principal foi criar uma interface limpa, intuitiva e totalmente adaptável para dispositivos móveis.

  • Interface Responsiva (Mobile Friendly)
  • Código semântico e limpo
  • Histórico de operações em tempo real
  • Controle de versão estruturado com Git
